# 07. Decisiones arquitectónicas

| **Código** | **Decisión** | **Motivo** |
|---|---|---|
| ADR-01 | Usar monolito modular y Clean Architecture. | Separar responsabilidades sin complejidad de microservicios. |
| ADR-02 | Utilizar adaptadores para APIs externas e internas. | Sustituir simuladores por integraciones autorizadas. |
| ADR-03 | Permitir registro provisional de pacientes. | No bloquear emergencias por falta de DNI. |
| ADR-04 | Separar frontend, backend y base de datos. | Facilitar seguridad, mantenimiento y pruebas. |
| ADR-05 | Centralizar autorización y auditoría. | Proteger información clínica sensible. |
