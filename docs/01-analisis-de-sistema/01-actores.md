# 01. Actores del sistema

| **Actor** | **¿Qué necesita realizar?** |
|---|---|
| **Admisión** | Registrar el ingreso, buscar al paciente y crear un registro provisional si no tiene DNI. |
| **Enfermería (triaje)** | Registrar motivo de consulta, signos vitales y prioridad determinada por el profesional. |
| **Médico de emergencia** | Consultar antecedentes disponibles, evaluar al paciente, registrar atención y solicitar exámenes. |
| **Administrador** | Gestionar usuarios, roles y configuración del sistema. |
| **RENIEC** | Proporcionar datos de identidad mediante una integración autorizada. |
| **Sistema de historia clínica** | Proporcionar antecedentes clínicos pertinentes mediante acceso autorizado. |
| **Sistema de seguros (SIS u otro)** | Informar el estado de afiliación o cobertura disponible. |
| **Laboratorio** | Recibir solicitudes y proporcionar resultados de exámenes. |
| **Diagnóstico por imágenes** | Recibir solicitudes y proporcionar informes o referencias a imágenes. |
| **Farmacia** | Consultar prescripciones iniciales y comunicar su estado cuando exista integración. |
