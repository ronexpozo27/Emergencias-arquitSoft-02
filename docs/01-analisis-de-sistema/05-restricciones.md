# 05. Restricciones

| **Restricción** | **Descripción** |
|---|---|
| Académica | La Fase 1 comprende solo documentación de arquitectura y diseño. |
| Tecnológica | Se plantea Angular, backend NestJS y PostgreSQL; no es una implementación existente. |
| Acceso a APIs | RENIEC, historia clínica y seguros requieren servicios y permisos específicos. |
| Datos | El prototipo académico usará información ficticia. |
| Clínica | El sistema registra el triaje decidido por un profesional; no diagnostica ni reemplaza al médico. |
| Operativa | La ausencia de DNI, seguro o conexión no impide iniciar la emergencia. |
