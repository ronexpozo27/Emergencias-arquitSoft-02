# 06. Drivers arquitectónicos

| **Código** | **Driver** | **Implicación** |
|---|---|---|
| DR-01 | Atención inmediata | Ingreso provisional y consultas externas no bloqueantes. |
| DR-02 | Datos sensibles | Roles, autenticación y auditoría. |
| DR-03 | Integraciones diferentes | Interfaces y adaptadores independientes. |
| DR-04 | Simplicidad académica | Monolito modular con arquitectura limpia. |
| DR-05 | Flujo clínico inicial | Módulos de admisión, triaje, evaluación y solicitudes. |
